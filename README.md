# PPE Guard

AI-Assisted PPE Compliance System — **frontend only** (TypeScript + React + Tailwind + Vite). Mock UI matching the Site Dashboard and Records designs.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide icons

## Run

```bash
npm install
npm run dev
```

## Pages

| Flow | Route |
| --- | --- |
| Login | `/login` |
| Site Dashboard | `/` |
| Records | `/records` |
| Create Toolbox | `/toolbox/create` |
| Settings | `/settings` |
