# GearSight

AI-Assisted PPE Compliance System — **frontend only** (TypeScript + React + Tailwind + Vite). UI aligned to the Live Feed + Records (list/grid) designs.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide icons

## Run

```bash
npm install
npm run dev
```

## Pages

| Flow | Route |
| --- | --- |
| Login | `/login` |
| Live Feed | `/` |
| Records (list / grid) | `/records` |
| About us | `/about` |
